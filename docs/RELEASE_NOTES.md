# 星律智表 AstraPulse 1.0.0

发布日期：2026-11-08

目标硬件：STM32U575RIT6 智能手表板

## 交付范围

- 从零构建的 STM32U575 + FreeRTOS 固件，不依赖旧工程业务代码。
- SSD1306 128×64 单色 OLED：开机动画、主表盘、Astra 风格菜单和中文功能页。
- 四键操作：PC12 上、PA4 下、PC11 返回、PA5 确认；支持 EXTI 从 STOP2 唤醒。
- RTC 日期时间、双闹钟、秒表。
- SHT20 温湿度采集。
- MAX30102 实时 PPG 采集、心率和血氧估算、波形与质量显示。
- MPU6050 驱动、自检和运动处理管线；传感器异常时明确显示 DEMO 数据。
- 恐龙游戏、声音设置、亮度与自动息屏、系统设置和个人信息。
- 双页 CRC Flash 日志：保存设置、个人信息、闹钟和游戏最高分。
- FreeRTOS Tickless Idle、SSD1306 Power Save、传感器休眠和 STM32 STOP2。
- 独立看门狗、任务栈余量监控、复位原因和 STOP2 统计。
- Windows PowerShell 构建、打包和 STM32CubeProgrammer 命令行烧录脚本。

## 已知限制

1. 当前实机 MPU6050/I2C4 硬件无法正常应答，因此运动页以醒目的 `DEMO` 标志展示示例数据；更换正常硬件后，现有驱动会自动切换到真实数据。
2. 电池未接入完成实机标定。无电池时显示 `--` 和空电池图标属于预期行为；百分比曲线是通用单节锂电池估算值。
3. 心率和血氧属于消费级算法估算，尚未与医疗设备完成定量对照，不可用于医疗诊断。
4. RTC 使用内部 LSI，长期走时精度低于外部 32.768 kHz LSE 晶振。
5. 尚未取得功耗仪测得的亮屏、息屏和 STOP2 电流数据。

## 升级说明

普通 ELF/HEX 烧录只改写 Bank 1，不会清除 Bank 2 最后两个页面中的配置日志。整片擦除会同时删除所有持久化设置。烧录和故障恢复步骤见 `OPERATIONS.md`。
